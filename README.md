## 🛑 The Problem with Passive Tracking
Passive time trackers let you lie to yourself. They run in the background while you drift into shallow work. **Time Master** replaces ambient tracking with a **technical audit of every hour**. Built on the philosophy that *friction is information*, this tool aggressively hijacks your screen at the end of a focus block, forcing you to confront exactly what you accomplished.

---

## 🚀 Core Protocols

### 1. The Enforcer Logic (Environmental Control)
When the timer hits zero, Time Master seizes system focus. Operating in a frameless, "Always on Top" kiosk mode, it forces itself above your IDE, browser, and all other windows. The interface locks your environment until you complete a rigorous Session Review or explicitly discard the session. 

### 2. Scientific Betting (Deep Work Focus)
Every session begins with a **Pre-Commitment**. You must define your goal before the timer engages. Upon completion, the app forces a **10-Point Audit** to generate your Data Dossier:
- **Execution:** *Activity, Output, Method*
- **Analysis:** *Utility Score (1-10), Friction, Uncertainty, Hypothesis Validity*
- **Momentum:** *Next Step, Pivot Required, Quick Win*

### 3. Infinite Pomodoro (Zero-Friction Cycles)
For classic, uninterrupted focus cycles, toggle **Simple Timer** mode. It automatically cycles between **Focus** and **Rest** periods. The timer auto-starts the next phase and maintains a persistent tally of your completed runs, keeping you in a flow state without manual interaction.

## 🎨 Avant-Garde Aesthetics & Customization

Designed with **Intentional Minimalism**, Time Master rejects bootstrapped layouts in favor of a modern, dark-mode glassmorphism aesthetic.

*   **12 Calibrated Themes:** Including *Nordic Light, Noir, Void*, and more.
*   **Surface Control:** Granular transparency settings for cards and inputs.
*   **Typographic Decoupling:** Separate color paths for System text vs. Data text to ensure perfect visual hierarchy.
*   **Audio Synthesizer:** Design your own cognitive triggers. Calibrate pitch frequencies (Hz), select waveforms (Sine, Square, Triangle, Sawtooth), or enable **Stochastic Mode** (randomized frequencies) to prevent auditory habituation.

## 🗄️ Data Dossier & Portability

Your work history is no longer a simple list—it's a professional ledger.

*   **Tiered Hierarchy:** Quickly scan collapsed views featuring mini-badges for Focus/Value scores and Goal status.
*   **Full CRUD Capabilities:** Edit past recordings to refine insights or delete anomalies.
*   **Portable JSON Node:** Specify exactly where your data is saved. Switch between different log files for different projects, with instant auto-loading on selection.

## 🛠️ Installation & Build Guide

### Development Environment
Make sure you have Node.js installed, then run:

```bash
# Install dependencies
npm install

# Start the dev environment (Vite frontend + Electron main process)
npm start
```

### Production Build
Compile Time Master into a native standalone executable.

**For Windows (NSIS & Portable):**
```bash
npm run compile
```

**For macOS (DMG & ZIP):**
```bash
npm run compile:mac
```
*The distributable binaries will be generated in the `release/` directory.*
